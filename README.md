## 🌟 3.0 核心突破：全領域元架構解壓縮協議 (Anti-Toothpaste Contract)

攻克「只說打地鼠，做出四不像；說要暱稱才補暱稱、說要分數才補分數」的擠牙膏難題：

### 1. 反擠牙膏 · 領域全景生產級閉環 (Panoramic Closed Loop)
無論任務多簡短，系統強制下游客戶端 AI 一次性交付五大生產級完備模組：
1. **身分與會話層 (Identity)**：玩家暱稱、身分狀態、歷史進度。
2. **生命週期狀態機 (Lifecycle FSM)**：首頁 ➔ 倒數 ➔ 進行 ➔ 分支 ➔ 結算重啟。
3. **核心循環機制 (Core Mechanics)**：核心玩法、碰撞計算、防作弊刷分。
4. **數值與進度推進 (Progression)**：關卡階梯、即時/最高分、連擊 Combo、接關 (Continue) 機制。
5. **數據持久化與防呆 (Persistence)**：LocalStorage 存檔、異常重置防崩潰。

### 2. 隱含黃金標配主動補全 (Implicit Gold Standards Auto-Infill)
絕不等待人類追問！系統主動替您補齊該領域的頂級業界預設，並以「假設宣告 (Declared Assumptions)」公開透明呈現。

### 3. 多端開發環境全域規格一鍵匯出
- **`.cursorrules`**：一鍵武裝 Cursor / Windsurf 編輯器。
- **`CLAUDE.md`**：一鍵配置 Claude Code 專案主記憶。
- **`GEMINI.md`**：一鍵同步至 Google Antigravity / Gemini CLI。
- **`JSON Payload`**：相容標準 OpenAI / Gemini API 請求封包。

## 🛡️ 指揮官三大防偏航核心法則 (速查卡)

1. **骨架 (Structure) 勝過血肉 (Details)**：先規定資料結構、有限狀態機 (FSM) 或 JSON 規格。
2. **紅線 (Negative Boundaries) 防堵捷徑**：「負向限制條件」字數必須與「需求條件」相當，明列絕對禁止事項。
3. **因果拆解 (If-Then Grounding)**：使用領域底層權威術語，拆解為「If [觸發條件] Then [狀態轉移與預期結果]」。

## 💾 本地備份與資料維護

- **API 金鑰安全性**：API Key 僅加密儲存在本地瀏覽器 `localStorage`，絕不上傳外部伺服器。
- **圖書館典藏備份**：
  - 定期點擊右上角 **「📤 匯出」** 下載備份 JSON 檔案。
  - 更換電腦或瀏覽器時，點擊 **「📥 匯入」** 即可無痛恢復歷次鑄造之宗師法典。
