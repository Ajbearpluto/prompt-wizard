## 🌟 3.2 核心突破與功能矩陣

### 1. 🧩 AgentDock 互動變數即時填空器 (Live Variable Fill-in Engine)
攻克「提示詞寫死無法重複複用、每次都要手動搜尋取代」的痛點：
- **智慧語法支援**：
  - `[VARIABLE]`：必填文字參數
  - `[VARIABLE?]`：選填參數（未填自動忽略）
  - `[VARIABLE:select:選項A,選項B,選項C]`：多選枚舉下拉選單
  - `{{VARIABLE}}`：相容 AWS Claude / Mustache 變數規範
- **即時表單渲染**：在結果面板下方自動生成美觀表單，使用者選取/填入數值時即時完成字串置換。
- **一鍵參數化萃取**：點擊「⚡ 一鍵自動萃取變數模板」，自動將靜態法典升級為具備插槽的標準模板！

### 2. 📊 雙軌視覺架構圖與學術配圖生成引擎 (LigphiDonk Diagram Engine)
解決「空有程式碼卻畫不出系統架構圖與流程圖」的痛點：
- **即時 Mermaid 拓撲圖**：自動提取或合成嚴謹的 Mermaid 狀態機與流程圖代碼，可一鍵複製至 Notion 或 GitHub。
- **頂會級 AI 繪圖 Prompt**：
  - 專用於 Midjourney / DALL-E 3 / Gemini Imagen 繪製技術架構圖。
  - 嚴格遵守**白底純淨排版**、**Okabe-Ito 色盲友好配色**（`#0072B2` 核心節點、`#D55E00` 決策閘、`#009E73` 成功態）、**高對比無幻覺框線**之學術出版級標準！

### 3. 🧭 圖書館員中介與探礦導航 (Mining Compass & Reverse Engineering)
- 輸入構想後，自動生成精準檢索關鍵詞與權重語法。
- 提供 **GitHub Top Stars**、**Awesome 系列**、**Hugging Face**、**Papers With Code**、**arXiv**、**Google Scholar** 六大頂級礦場一鍵直達。
- 指揮官探礦 ➔ 丟回網址 ➔ 零一啟動白帽逆向工程！

### 4. 🧠 多端全域規範一鍵匯出矩陣
- **`SKILL.md (Agent)`**：官方 Agent Skill 規格（含 YAML frontmatter）。
- **`AgentDock MDX (.mdx)`**：相容 AgentDock 官方提示詞庫格式（含 frontmatter + 參數插槽）。
- **`學術配圖 Prompt (.txt)`**：一鍵下載架構圖 AI 繪圖指令。
- **`.cursorrules` / `CLAUDE.md` / `GEMINI.md` / `JSON Payload`**：原生跨端相容。

### 3. 🎯 智慧領域即時路由探測 (Smart Domain Router)
輸入內容時，即時標記並載入對應領域的專業典範與元素庫：
- 🎮 **遊戲與互動機制**：自動帶入狀態機 FSM、AABB 碰撞、Combo 連擊、接關 Checkpoint。
- 📚 **文教與詞彙學習**：自動帶入艾賓浩斯間隔重複、語境辨析、動態難度回饋。
- 📈 **複雜決策與量化博弈**：自動帶入滑點風控、蒙地卡羅檢驗、極端黑天鵝防禦。
- 🛡️ **零一 · 白帽資安防禦**：自動帶入零信任架構、輸入過濾、安全審計追蹤。
- 💻 **軟體架構與系統工程**：自動帶入 API 契約、冪等性保證、異常處理狀態機。

### 4. 反擠牙膏 · 領域全景生產級閉環 (Panoramic Closed Loop)
無論任務多簡短，系統強制下游客戶端 AI 一次性交付五大生產級完備模組：
1. **身分與會話層 (Identity)**：玩家暱稱、身分狀態、歷史進度。
2. **生命週期狀態機 (Lifecycle FSM)**：首頁 ➔ 倒數 ➔ 進行 ➔ 分支 ➔ 結算重啟。
3. **核心循環機制 (Core Mechanics)**：核心玩法、碰撞計算、防作弊刷分。
4. **數值與進度推進 (Progression)**：關卡階梯、即時/最高分、連擊 Combo、接關 (Continue) 機制。
5. **數據持久化與防呆 (Persistence)**：LocalStorage 存檔、異常重置防崩潰。

## 🛡️ 指揮官三大防偏航核心法則 (速查卡)

1. **骨架 (Structure) 勝過血肉 (Details)**：先規定資料結構、有限狀態機 (FSM) 或 JSON 規格。
2. **紅線 (Negative Boundaries) 防堵捷徑**：「負向限制條件」字數必須與「需求條件」相當，明列絕對禁止事項。
3. **因果拆解 (If-Then Grounding)**：使用領域底層權威術語，拆解為「If [觸發條件] Then [狀態轉移與預期結果]」。
